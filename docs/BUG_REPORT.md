# Воспроизводимая ошибка

Не прикладывайте переписки, коды сопряжения, секрет помощника или необработанный dumpsys.

```text
Hinge Lab: версия / режим
Устройство: модель, Android, One UI, номер сборки
Приложение: название, версия; какой именно экран
Исходное состояние: внутренний/внешний, заблокирован/разблокирован
Шаги:
1. ...
2. ...
3. ...
Ожидание:
Результат отдельно на внутреннем и внешнем:
Что происходит после полного закрытия/раскрытия:
Повторяемость: N из M (медленно/быстро/с остановкой)
Возвращается ли работа после «Остановить»:
Предыдущий сценарий: другое приложение / блокировка / неудачный перенос
Короткий обезличенный журнал:
```

Чёрная картинка во время жеста, отсутствие эффекта при работающем приложении и зависший телефон — разные симптомы. Укажите, меняется ли угол и оживает ли приложение после конечного положения. Не повторяйте эксперимент до восстановления управления.
